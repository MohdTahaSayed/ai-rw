# 1. Final 60:20:20 Dataset Split

The project requirements for the LLM fine-tuning stage specify a:

- 60% Training set
- 20% Validation set
- 20% Test set

Therefore, the final malware dataset was split using stratified sampling based on the target variable `Type`.

### Final Dataset

The final merged dataset contains:

- 29,489 samples
- 318 ML features
- 1 SHA256 identifier
- 1 target column (`Type`)
- 320 total columns

### Final Split

| Split | Samples | Percentage |
|---|---:|---:|
| Training | 17,693 | 60% |
| Validation | 5,898 | 20% |
| Test | 5,898 | 20% |
| **Total** | **29,489** | **100%** |

The split was performed using stratification so that the distribution of the seven malware classes remained approximately consistent across all three subsets.
