# LazyPredict Baseline Results

## Overview

LazyPredict was used to benchmark multiple traditional machine-learning classifiers on the prepared malware dataset.

### Dataset

- Samples: 29,489
- Features: 318
- Classes: 7
- Training samples: 17,693
- Validation samples: 5,898
- Test samples: 5,898

The validation set was used for this baseline experiment. The test set was kept separate for final evaluation.

---

---

## Best Baseline

**XGBClassifier** achieved the strongest overall validation performance:

- Accuracy: **88.91%**
- Balanced Accuracy: **88.98%**
- F1 Score: **89.04%**
- ROC-AUC: **98.71%**

---

## Key Observations

- Tree-based ensemble methods performed substantially better than most linear models.
- XGBClassifier achieved the highest validation accuracy and F1 score.
- LGBMClassifier achieved a slightly higher ROC-AUC (**98.73%**) but lower accuracy and F1.
- Classical ML provides a strong reference baseline for subsequent model experiments.
