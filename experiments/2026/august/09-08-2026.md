# Experiment - 2026-08-09

## Objective
Perform comprehensive data analysis, validation, cleaning, and integration of the Windows Malware datasets to prepare a high-quality master dataset for malware classification and feature engineering.

## Dataset

Four Windows malware feature datasets were analyzed:

1. **API_Functions.csv**
   - Samples: 29,505
   - Features: 21,920

2. **DLLs_Imported.csv**
   - Samples: 29,498
   - Features: 631

3. **PE_Header.csv**
   - Samples: 29,807
   - Features: 54

4. **PE_Section.csv**
   - Samples: 29,760
   - Features: 92

Each dataset uses **SHA256** as the unique executable identifier and **Type** as the malware family label.

---

## Work Completed

### 1. Dataset Exploration
- Analyzed dataset dimensions.
- Verified feature names and data types.
- Examined memory usage of each dataset.
- Inspected label distributions.
- Checked missing values and constant features.
- Generated feature usage statistics for API and DLL datasets.

### 2. Memory Optimization
- Converted binary API and DLL features from **int64** to **uint8**.
- Reduced API dataset memory usage from approximately **4.8 GB to 620 MB**.
- Reduced DLL dataset memory usage from approximately **145 MB to 21 MB**.
- Optimized datasets for faster processing.

### 3. Duplicate Analysis
- Identified duplicate SHA256 values across all datasets.
- Verified duplicate records.
- Removed duplicate malware samples while preserving unique executables.

Duplicate SHA256 removed:
- API dataset: **5**
- DLL dataset: **3**
- PE Header: **0**
- PE Section: **0**

### 4. Dataset Integration
- Compared SHA256 identifiers across all four datasets.
- Found **29,489 common malware samples** present in every dataset.
- Successfully merged all datasets using SHA256.

### 5. Final Data Validation
Performed integrity checks on the merged dataset:

- Duplicate SHA256: **0**
- Duplicate rows: **0**
- Missing values: **0**
- Unique malware samples: **29,489**

The merged dataset is now fully consistent and ready for machine learning.
