1. Objective
Prepare and fine-tune deepseek-ai/deepseek-coder-1.3b-base for
seven-class Windows PE malware-family classification using: - 4-bit
QLoRA (NF4) - LoRA adapters - Masked Supervised Fine-Tuning (loss on
answer tokens, not prompt tokens) - Two-process distributed training
across two Tesla T4 GPUs

The model input contains all 318 numerical PE features, including
zero-valued features. SHA256 is metadata, not a model feature. Type is
the target label.
