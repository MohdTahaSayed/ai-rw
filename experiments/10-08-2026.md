# Experiment - 2026-08-10

## Objective

Start Phase 2 of the malware analysis project by preparing the Windows Malware dataset for future LLM fine-tuning. The focus was on understanding the dataset structure, validating data integrity, and beginning statistical feature selection.

---

## Dataset

Windows Malware Dataset

Files analyzed:
- API_Functions.csv
- DLLs_Imported.csv
- PE_Header.csv
- PE_Section.csv

Combined information:
- ~29.5K malware samples
- API features
- Imported DLLs
- PE header metadata
- PE section metadata

---

## Work Completed

- Loaded and explored all four dataset components.
- Optimized memory usage for the API dataset by converting binary features to `uint8`.
- Verified dataset shapes and schema consistency.
- Identified common SHA256 hashes across all datasets.
- Removed duplicate SHA256 entries and duplicate records.
- Merged API, DLL, PE Header, and PE Section datasets into a unified dataset.
- Verified that the merged dataset contained no duplicate samples or missing values.
- Performed API frequency analysis to study feature sparsity.
- Applied Variance Threshold feature selection, reducing API features from 21,918 to 2,720 informative candidates.
- Planned the next feature selection stages using Mutual Information, Chi-Square, and Random Forest importance.

---

## Results

- Final merged dataset: **29,489 unique malware samples**
- Duplicate SHA256 entries removed successfully.
- No missing values after merging.
- API feature space reduced by approximately **87.6%** using Variance Threshold.
- Established the preprocessing pipeline for constructing the final fine-tuning dataset.
