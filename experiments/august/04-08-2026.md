# Experiment - 2026-08-01

## Objective
Identify and evaluate publicly available malware datasets to select the most suitable dataset for malware classification research.

## Dataset
Multiple malware datasets from Kaggle, GitHub, and research repositories, including datasets containing API calls, DLL imports, PE headers, opcode features, malware traffic, and malware family labels.

## Work Completed
- Explored several malware datasets based on:
  - Number of samples
  - Number of features
  - Feature types
  - Label availability
  - Research applicability
- Compared static and dynamic malware analysis datasets.
- Shortlisted the Windows Malware Dataset containing multiple complementary feature files.
- Discussed the dataset selection with the project manager and confirmed that the dataset with the richest feature representation should be used.

## Results
- Selected the Windows Malware Dataset for further research.
- Identified four major feature files:
  - API_Functions.csv
  - DLLs_Imported.csv
  - PE_Header.csv
  - PE_Section.csv
- Established the overall direction for dataset preprocessing and analysis.

## Next Steps
- Perform exploratory data analysis on each feature file.
- Analyze feature distributions, dataset quality, and preprocessing requirements.
