# Preprocessing and Model Development

## 1. Overview

After constructing and validating the unified malware dataset, the next stage focused on preparing the data for machine learning and developing classification models.

The main objectives were:

- Separate identifiers, features, and target.
- Create a stratified train/test split.
- Prevent sample leakage.
- Analyze feature types.
- Build a leakage-safe preprocessing pipeline.
- Train baseline classification models.
- Compare different model families.
- Select the strongest baseline model.
- Perform hyperparameter optimization.
- Prepare the model for detailed error analysis.

---

# 2. Feature and Target Separation

The final dataset contains:

- SHA256 — sample identifier
- Type — classification target
- ML features — numerical feature representation

SHA256 was explicitly excluded from the ML feature matrix.

The `Type` column was separated as the target variable.
