# Feature Reduction & API/DLL Dataset Integration

## 1. Overview

Following the initial frequency and Mutual Information analysis, the selected API and DLL features were further processed to remove redundancy and create a single compact behavioral dataset.

The main objectives were:

1. Remove redundant DLL features.
2. Validate selected feature columns.
3. Align API and DLL samples using SHA256.
4. Remove duplicate samples.
5. Combine API and DLL behavioral features.
6. Verify label consistency.

---

# 2. DLL Correlation Analysis

The 34 MI-qualified DLL features were analyzed for pairwise correlation.

A correlation threshold of:

**|r| >= 0.90**

was used to identify highly redundant features.

Several strongly correlated DLL groups were identified.

Examples include:

- `libgimp-2.0-0.dll` ↔ `libgimpbase-2.0-0.dll`
- `libgimpwidgets-2.0-0.dll` ↔ `libgtk-win32-2.0-0.dll`
- `libgtk-win32-2.0-0.dll` ↔ `libgimpui-2.0-0.dll`
- `msvcp90.dll` ↔ `msvcr90.dll`

Redundant features were removed while retaining the feature with the stronger MI score where applicable.
